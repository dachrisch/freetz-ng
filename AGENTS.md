# AGENTS.md

## What this repository is

Freetz-NG is a firmware-modification framework for AVM FRITZ!Box routers (and other AVM devices); it is a fork of Freetz. The build downloads the original AVM firmware, unpacks it, adds selected packages and patches, repacks it and produces a flashable image. Configuration uses the Linux kconfig/menuconfig system, target code is cross-compiled (MIPS/ARM) with project toolchains, and the tree carries 300+ optional packages and libraries. Default branch: `master`.

## Build, verify, flash (run from the repository root)

```bash
tools/prerequisites install    # install host build dependencies (docs/prerequisites/README.md)
tools/prerequisites check      # verify the build environment
make menuconfig                # select device/packages/toolchain; writes .config
make olddefconfig              # refresh .config after a pull or config change
make                           # full build; output images in images/
make firmware                  # build the firmware image
make firmware-nocompile        # repack without recompiling packages
make help                      # list all make targets
make test                      # builds the modified image, then reports "no tests defined"
```

Package work uses `make <pkg>-precompiled`, `<pkg>-recompile`, `<pkg>-dirclean`, `<pkg>-autofix`; cleaning uses `make clean` / `dirclean` / `distclean`. There is no automated test suite — verification means building and testing on real hardware. Flashing: `tools/push_firmware -h` (see [docs/INSTALL.md](docs/INSTALL.md)).

## Safety policies

- **Scope**: for docs-only tasks keep changes to documentation; do not modify code, CI workflows, configs or lockfiles unless explicitly asked.
- **Environment**: build on Linux x86_64 with `umask 0022` (enforced by the Makefile) and a filesystem that preserves Unix permissions. Cygwin, WSL and AArch64 are unsupported; prebuilt toolchains require AVX2, otherwise select `FREETZ_BUILD_TOOLCHAIN=y`. Do not run the build as root — `fwmod` re-enters via `fakeroot`.
- **Generated files**: do not hand-edit `.config` (owned by menuconfig), `docs/prerequisites/README.md` (generated by `docs/generate.sh`) or generated `Config.in` files. Regenerate patches through `make <pkg>-autofix`.
- **Destructive operations**: `make distclean` and `git clean -fd` delete local work — confirm before running. Flashing overwrites device flash and is model-specific: only flash an image built for the exact device, back up the current image/config first, and never commit device credentials or signing-key passwords.
